# 💣 지뢰찾기

## 게임 소개

숫자 단서를 이용해 지뢰가 있는 칸을 찾아 표시하고, 안전한 칸을 모두 여는 클래식 지뢰찾기 게임입니다. 브라우저에서 별도 설치 없이 플레이할 수 있으며, 전통적인 회색 타일과 디지털 카운터 스타일로 구성했습니다.

## 어떻게 만들었나요

먼저 게임 규칙과 화면 요소를 PRD로 정리하고, 그 내용을 구현 계획으로 확인한 뒤 Vanilla JavaScript로 구현했습니다. 초급·중급·고급과 사용자 지정 보드 크기를 지원하며, 첫 클릭 안전, 빈 칸 연쇄 열기, 깃발과 물음표 마킹, 승패 판정과 타이머를 포함합니다.

## freeform 버전과 비교했을 때

freeform 버전은 간단한 프롬프트를 바탕으로 핵심 지뢰찾기 기능을 빠르게 구현했습니다. PRD 버전은 첫 클릭 안전 규칙과 승리·패배 조건, 타이머 및 남은 지뢰 수처럼 구체적인 요구사항을 계획 단계에서 확인해 빠짐없이 반영했습니다. 이 저장소에서는 PRD를 기준으로 구현을 보완하고 난이도와 커스텀 설정까지 추가했습니다.

## 실행 방법

- [GitHub Pages에서 플레이](https://themodernalamo.github.io/minesweeper/)
- 로컬 실행: 저장소를 내려받은 뒤 `index.html`을 브라우저에서 엽니다.

## 커스터마이징한 부분

- 초급(9×9, 지뢰 10개), 중급(16×16, 지뢰 40개), 고급(16×30, 지뢰 99개)과 커스텀 난이도
- 커스텀 보드의 높이·너비(각 5~30칸)와 지뢰 수 설정 및 안전한 첫 클릭을 위한 입력 검증
- 첫 클릭과 주변 칸의 안전 보장, 빈 칸 연쇄 오픈
- 우클릭으로 없음 → 깃발 → 물음표 → 없음 순환, 깃발 수에 따른 남은 지뢰 표시
- 클래식 지뢰찾기에서 영감을 받은 입체 타일, 디지털 카운터, 재시작 얼굴 버튼
- 승리·패배 안내, 종료 시 정지하는 타이머, 모바일에서 스크롤 가능한 큰 보드

난이도별 보드와 지뢰 수는 각각 9×9·10개, 16×16·40개, 16×30·99개이며, 커스텀은 높이와 너비를 각각 5~30칸으로 설정할 수 있습니다. 최고 기록 저장과 사운드는 포함하지 않았습니다.
