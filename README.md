# 지뢰찾기

좌클릭으로 칸을 열고 우클릭으로 깃발을 표시하는 브라우저 지뢰찾기 게임입니다. 9×9 격자에 지뢰 10개가 배치됩니다. 첫 클릭은 항상 안전하며, 숫자는 주변 8칸에 있는 지뢰 수를 알려줍니다.

## 게임 소개

모든 지뢰가 없는 칸을 열면 승리하고, 지뢰가 있는 칸을 열면 게임이 끝납니다. 빈 칸을 열면 연결된 빈 영역이 자동으로 열립니다. 깃발은 우클릭으로 표시하거나 해제할 수 있습니다. 열린 숫자 칸에서 좌우 클릭을 함께 하거나 휠 버튼을 누르면, 주변 깃발 수가 숫자와 일치할 때 아직 열리지 않은 주변 칸을 엽니다.

## 어떻게 만들었나요

HTML, CSS, Vanilla JavaScript를 각각 별도 파일로 분리했습니다. 격자 상태와 타이머는 JavaScript로 관리하고, 첫 클릭 후 지뢰를 배치해 첫 칸이 안전하도록 했습니다.

## freeform 버전과 비교했을 때

이 저장소에는 단일 구현만 포함되어 있어 freeform 및 PRD 버전 간 비교는 적용되지 않습니다.

## 실행 방법

저장소의 `index.html`을 브라우저에서 열면 실행됩니다. 별도의 패키지 설치나 빌드 과정은 필요하지 않습니다.

## 커스터마이징한 부분

- 9×9 격자와 지뢰 10개로 구성했습니다.
- 첫 클릭 안전, 빈 영역 자동 열기, 승리·패배 상태 및 재시작을 지원합니다.
- 남은 지뢰 수와 경과 시간을 표시하고, 화면 크기에 맞춰 격자가 조정됩니다.
